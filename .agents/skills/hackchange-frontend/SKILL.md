# HackChange — фронтенд

## Ветка и область правок

- Работай в ветке `frontend`. Перед правками проверяй ветку. Если `frontend` уже открыта в отдельной рабочей копии, используй её.
- Правь `frontend/` и [журнал фронтенда](../../../docs/frontend-handoffs.md). Читай контракт в `backend/app/api/chat.py` и `backend/app/api/sources.py`. Если требуется изменение контракта, зафиксируй запрос интеграции в журнале.
- Используй HTML, CSS и чистый JavaScript. FastAPI раздаёт файлы из `frontend/`, запросы идут на тот же origin.
- После правок перечисли файлы, проверенные сценарии и блокеры. Предложи сообщение коммита. Создавай коммит по явной команде пользователя, для пуша получи отдельное разрешение.

## Дизайн и поведение

- Язык интерфейса русский. Используй светлый нейтральный фон, тёмно-синий текст, синий для действий и янтарный для уточнения и подсветки цитаты. Оставляй достаточно места для чтения длинных ответов.
- На широком экране держи чат рядом с панелью источника. На узком экране открывай источник так, чтобы можно было вернуться к реплике. Сохраняй видимый фокус, работу с клавиатурой и читаемость без анимации.
- Передавай историю через `POST /api/chat`. Обрабатывай загрузку, полный и частичный ответ, уточнение, отказ и техническую ошибку. При повторе запроса сохраняй одну копию реплики.
- По клику открывай карточку источника с редакцией и дословной цитатой. В исходном документе выделяй диапазон `line_start`–`line_end` включительно. Выводи ответы, цитаты и документы как текст.

## Проверка и продолжение

- Начинай с открытых задач в журнале. Проверяй JavaScript через `node --check frontend/chat.js`. Тестируй в браузере, начиная с `ASSISTANT_STUB=1` и FastAPI, включая узкий экран.
- Критерий MVP — пользователь задаёт вопрос по П-17/2024, уточняет дату подписания спецификации и открывает цитату и строки исходного документа. Проверь также отказ и повтор после технической ошибки.
- Обновляй журнал после реализации или проверки. Указывай, какой сервер или имитацию API использовал и что ещё требует реальной модели. По команде «Продолжи фронтенд» возобновляй задачи, для которых появились нужные входы.

Пример. `$hackchange-frontend` Продолжи фронтенд. Проверь сценарий уточнения и открытия источника в браузере.
