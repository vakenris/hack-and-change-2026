# Стыки блока данных HackChange

Типы и точки подключения определяет интеграция в `assistant_core/contracts.py` и `assistant_core/assistant_service.py`. Пока этих файлов нет в `data`, сверяй их в `main` или на согласованном коммите интеграции.

| Направление | Что передаём | Как проверяем |
| --- | --- | --- |
| Интеграция → данные | Типы `QueryFacts`, `EventDate`, `Fragment`, `Selection`, интерфейс `KnowledgeStore` и вызовы в `build_assistant()`. | Сигнатуры и поля совпадают с текущим контрактом. |
| Данные → интеграция | Готовую SQLite, отчёт сборки и примеры вызова `knowledge_store.open_store(path)`, `retrieval.search(store, facts, limit)` и `versions.select(store, candidates, facts)`. Хранилище предоставляет `get_fragment(fragment_id)` и `get_document_text(document_id)`. | Ядро открывает базу, находит применимый пункт и извлекает исходный текст. |
| Данные → ML | Контрольные вопросы, ожидаемые пункты и редакции, применимые фрагменты и примеры `Selection` с пробелами. | ML различает отсутствие нужной редакции и запрос недостающего факта. |
| ML → данные | Исходный вопрос или диалог, извлечённые `QueryFacts`, фактические кандидаты и ожидаемый результат. | Расхождение можно воспроизвести на том же входе. |

#### Контрольные входы для интеграции и ML

```python
from datetime import date

from assistant_core import knowledge_store, retrieval, versions
from assistant_core.contracts import EventDate, QueryFacts

store = knowledge_store.open_store("data/processed/knowledge.sqlite")
facts = QueryFacts(
    "П-17/2024. Доставка 02.10.2024. Какой адрес?",
    document_refs=["П-17/2024"],
    dates=[EventDate("delivery", date(2024, 10, 2))],
)
selection = versions.select(store, retrieval.search(store, facts, 12), facts)
assert selection.missing_fact == "дата подписания спецификации"
assert selection.gaps and all(fragment.clause != "3.2" for fragment in selection.applicable)
```

| Запрос и факты | Ожидаемое основание или пробел |
| --- | --- |
| `П-17/2024, п. 3.2`, `spec_signed` 30.09 или 01.10.2024 | Исходная редакция, строка 14. |
| `П-17/2024, п. 3.2`, `spec_signed` 02.10.2024 | Допсоглашение № 1, строки 6–7. `store.get_fragment("frag-9b9b9eb7d974ce5403da4a9a")` открывает цитату, `store.get_document_text(fragment.document_id)` открывает весь TXT. |
| `Регламент согласования договоров, п. 2.4`, `deal` 28.02 и 01.03.2025 | Редакции от 10.01.2023 и 01.03.2025 соответственно. Для 09.01.2023 — пустой `applicable`, причина в `gaps`, `missing_fact=None`. |
| `ООО «Альфа-Трейд», п. 6.2` и `ООО «Альфа-Трейдинг», п. 6.1` | П-17/2024 о претензии и ПТ-05/2023 о гарантийном талоне соответственно. |
