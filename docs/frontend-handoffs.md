# Стыки фронтенда HackChange

| Что нужно фронтенду | Откуда | Критерий проверки |
| --- | --- | --- |
| `POST /api/chat` принимает `{messages: [{role, content}]}` и возвращает текст, статус и источники. | Интеграция. `backend/app/api/chat.py`. | Последующий вопрос отправляет предыдущие реплики вместе с новой. |
| `GET /api/sources/{fragment_id}` возвращает редакцию, цитату и `source_url`. `GET /api/documents/{document_id}` возвращает текст и диапазон строк. | Интеграция. `backend/app/api/sources.py`. | Цитата и подсветка совпадают с выданными строками. |
| Запуск с реальной SQLite и моделью. | Интеграция, data и ML. | Сценарий П-17/2024 проходит в браузере на реальных данных. |

## Локальный запуск

Из рабочей копии ветки `frontend` установи зависимости в активное окружение Python и запусти FastAPI.

```powershell
python -m pip install -r requirements.txt
$env:ASSISTANT_STUB = '1'
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Открой `http://127.0.0.1:8000/`. Для тестового режима используй пример про адрес доставки и уточнение «Спецификация подписана 02.10.2024». Заглушка для этого сценария выдаёт условные цитаты. Для реального режима выставь `ASSISTANT_STUB=0`, укажи доступную SQLite через `KNOWLEDGE_DB` и задай `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL` в окружении.

### Минимальный интерфейс чата

- Убраны служебные подписи, дублирующие заголовки и подсказки. Примеры показаны отдельными вопросами. Панель источника занимает место только после выбора цитаты. Подписи к полю ввода, репликам и выделенным строкам доступны экранному диктору.
- Проверено во встроенном браузере на ширине 1280 и 390 пикселей через локальный FastAPI 0.143.2 с `ASSISTANT_STUB=1`. Сценарий П-17/2024 прошёл от выбора примера и отправки по Enter до уточнения даты, открытия источника и выделения дословной цитаты. На узком экране источник открывается под чатом без горизонтальной прокрутки. Закрытие кнопкой или Escape возвращает фокус к источнику в ответе.
- Проверены частичный ответ, отказ и повтор при воспроизводимом HTTP 503. После повтора в чате остаётся одна копия вопроса. `node --check frontend/chat.js` и семь тестов `tests/test_web.py` прошли.
- База `data/processed/knowledge.sqlite` есть локально. Проверка с реальной моделью требует настроек подключения к LLM.
